# GitHub 外掛更新器（GitHub Plugin Updater）

版本：**0.1**；作者：**SamLiao & Codex**；授權：**GPL v3**；最低 calibre：**9.19.0**。本倉庫自行開發。

## 用途與安裝

從多個公開 GitHub 庫追蹤已安裝的 calibre 外掛。預設來源為 `SamLaio/calibreMetadatImplode`，每個來源可提供多支外掛。功能思路參考 [Obtainium](https://github.com/ImranR98/Obtainium) 的直接追蹤發行來源方式，沒有沿用其程式碼。

1. 以根目錄 `python -B build_release.py` 打包，安裝 `dist/GitHub Plugin Updater-zh_TW-release.zip` 並重啟 calibre。
2. 在「偏好設定 → 工具列與選單」加入「GitHub 外掛更新」。
3. 按「管理來源」，每行輸入一個 `owner/repo` 或 GitHub 庫網址；最多 30 個公開庫。
4. 按「檢查更新」。檢查只下載 Release 資訊與 JSON 清單，不下載外掛 ZIP；各來源失敗個別列出，其他來源繼續檢查。
5. 新包有來源身分檔時自動記住綁定；舊包或切換分支時，勾選對應項目，按「綁定勾選來源」確認。每支外掛只綁定一個來源，同名不自動接管。
6. 勾選「可更新」項目，按「更新勾選」並確認後，才下載、備份及安裝。完成後按「重新啟動 calibre」載入新版；按鈕預設灰色，至少一支外掛成功更新才啟用，包含更新器自身。重啟前不繼續更新。

## 身分、SHA-256 與版號

每個 ZIP 的 `github-plugin-identity.json` 保存固定 `id`、`source` 與內容 `sha256`。本機設定 `plugins/github_plugin_updater.json` 保存來源及綁定。固定 ID 不隨版號改動；0.1 不支援外掛改名遷移。更新器本身也列入清單，沿用同一流程並在獨立程序安裝，重啟後才載入新版。

1. 讀取本機 ZIP 身分檔的內容 `sha256`，與清單 `sha256` 比較；有身分檔時不重新掃描外掛內容。舊包沒有身分檔才計算內容 SHA 作為初次基準。相同便結束，不比較版號。
2. SHA 不同，才比較 JSON 的版號及相容性；只允許較新版，不自動降版。
3. 同版但內容不同，顯示「同版內容不符，請來源修正版號」，不提供覆蓋更新。來源維護者必須遞增版號。
4. 下載後再次檢查大小、完整 ZIP 的 `package_sha256`，實算內容 SHA 並核對身分檔與清單，再核對包內 ID／來源、程式宣告名稱／版號／相容性，避免清單與附件不符。ZIP 驗證通過之前不載入其程式。

內容 SHA 依路徑排序，將每個檔名、內容長度與解壓後內容納入計算；排除身分檔本身、目錄項目、ZIP 時間戳與壓縮屬性，避免自我引用，也不受昨天或今天重包影響。另以完整 ZIP 計算 `package_sha256`，只作下載完整性驗證。打包器仍固定時間戳、權限與順序，相同內容可重現相同 ZIP。程式、翻譯或說明改變時，必須遞增版號。

綁定包含安裝時內容 SHA。若其他更新器／手動安裝使來源身分消失或改變，需重新確認綁定；檢查後本機 ZIP 又變動則拒絕覆蓋。官方更新器仍可能更新同名外掛，本工具不攔截官方更新行為。

## 來源清單與發布

各來源的最新正式 GitHub Release 必須附上 `plugins.json` 及清單列出的 ZIP；不接受預發行、原始碼 ZIP 或只有 ZIP 而沒有清單的第三方庫。JSON 已包含版號，無須下載外掛才得知版本。

根目錄 `plugins.json` 是維護用的清單快照；`build_release.py` 產生 `dist/plugins.json`，發布時將該檔與同批 ZIP 一起上傳。更新器使用同一 Release 的清單與附件，避免 `main` 與已發布安裝包不同步。根目錄快照也須在發行前同步。

格式為 `calibre-github-plugins`、`schema: 1`。詳細範例及第三方來源製作方式見 [清單規格](./MANIFEST.md)。

## 備份與限制

安裝前，先在 calibre 設定目錄 `github-plugin-updater-backups/時間-隨機識別/` 保存舊 `previous.zip` 及登錄、啟用狀態、自訂字串的 `state.json`，再載入新版程式。一般安裝失敗會回復原包與登錄，備份仍保留。按「開啟備份資料夾」可取得舊包，從 calibre「從檔案載入外掛」手動還原。

- 備份不是整個設定目錄的快照，不包含外掛私有 JSON、書庫或書檔；完整設定備份請使用 Plugin Backup。`state.json` 可能含自訂設定，請妥善保管。
- 安裝在獨立 calibre 背景程序執行，保留啟用／停用狀態；不讓操作介面因網路請求卡住。中途關閉主程式、斷電或磁碟損壞不能保證自動回復，請使用保留的備份。
- 不提供背景自動安裝、私有庫認證、無清單庫的猜測配對、新外掛首次安裝或跨來源自動選版。
- SHA 只能核對下載內容與來源清單一致，不是作者簽章。加入來源代表信任其可執行程式；僅允許 GitHub HTTPS 下載並限制大小與重新導向。
- 快速檢查信任身分檔的內容 SHA，並非每次檢查都驗證本機所有程式是否遭修改；安裝前會實算舊包內容，發現與身分檔不符即停止覆蓋。
- 來源的正式 Release 必須提供 `plugins.json`；缺少時顯示錯誤，不會改抓不匹配的 ZIP。

## 驗證

Windows、calibre 9.19：11 項核心測試、10 項原生 Qt／安裝／回復測試及 3 項打包測試，涵蓋 JSON-only 檢查、SHA 優先、來源綁定、來源失敗隔離、拒絕降版及同版變更、校驗失敗、身分／宣告不符、更新備份、停用狀態、安裝失敗回復、真正背景程序及自我更新／重啟按鈕狀態。所有設定與測試外掛均在 `dist/` 隔離目錄，不變更正式設定。

尚未驗收 macOS／Linux、真實第三方清單或中途斷電恢復。測試方式見 `tests/`；先打包，再以 Python 執行 `test_core.py`、`test_build.py`；`test_native.py` 使用 `calibre-debug -e` 並將 `CALIBRE_CONFIG_DIRECTORY` 指向 `dist/`。
