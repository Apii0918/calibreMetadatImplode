# 單庫單外掛來源規則

適用於 GitHub Plugin Updater **0.3**。目前先支援：

`https://github.com/HamsterExAstris/calibre-azw6-image-merge`

## 配對資料

| 項目 | 規則 |
| --- | --- |
| 模式 | `single`，一個庫對應一支外掛。 |
| calibre 名稱 | `AZW6 Image Merge`，須與下載包實際宣告一致。 |
| 固定 ID | `hamsterexastris.azw6-image-merge`，不與本倉庫修訂版合併。 |
| 版號 | 最新正式 Release 的數字標籤，可有 `v`，例如 `v1.0.0` 或 `1.0.0`。 |
| 附件 | 精確配對唯一的 `AZW6ImageMerge.zip`，不選 GitHub 自動產生的原始碼 ZIP。 |

規則放在 `src/singles.py`；一般無規則來源仍須提供 `plugins.json`，本版不自動猜測任意單外掛庫。

## 檢查順序

1. 取得 `/releases/latest` JSON，不先下載 ZIP。排除草稿、預發行及不能解析為數字版號的標籤。
2. 依固定名稱、來源及 ID 找到目前安裝與綁定。名稱相同但來源不同時，分開列出，不自動接管。
3. GitHub 有提供附件 digest，而且本機已保存與目前內容相符的附件 SHA 時，先比較 digest；相同即顯示附件相同。
4. 沒有 digest、沒有校驗基準或摘要不同時，比較標籤版號，提示新版、同版或較舊版。未提供摘要一律顯示「來源未提供附件 SHA」。
5. 保存過的附件 ID 若與遠端不同，可以提示附件已更換，但 ID、上傳時間及檔案大小都不能代替 SHA，也不能證明內容有變。

## 勾選後的驗證

確認後才下載精確配對的 ZIP。若有 digest，完整 ZIP SHA 必須一致；沒有 digest 時明確提示校驗不足，僅計算本機 SHA 留存，不宣稱已對上作者公布的摘要。

接著檢查大小、ZIP 結構及解壓限制，保留舊包與登錄備份，再載入原包檢查名稱、實際版號、最低 calibre 與平台。原包不必包含我們的身分 JSON；名稱或標籤版號不符、缺少依賴或載入失敗，都不會完成覆蓋安裝。

成功後保存來源、固定 ID、附件 ID、完整 ZIP SHA 與本機內容 SHA。更新前備份、失敗回復、保留停用狀態及重啟規則與其他模式一致。

## 預設與使用者設定

內建規則只是增加辨識能力，不代表訂閱來源。全新安裝預設只有 `SamLaio/calibreMetadatImplode`；AZW6 與 kiwidude 必須由使用者自行加入。更新或重裝不改寫既有來源清單，也保留使用者刻意設定的空清單。

同名的本倉庫修訂版與上游版不能並存；切換來源需明確勾選及確認，同批選兩個同名來源會被擋下。上游版可能沒有本倉庫的翻譯與相容性修正。

## 實際驗證與相容性提醒

2026-11-22 查到上游最新正式版為 `v1.0.0`，附件為 `AZW6ImageMerge.zip`，GitHub 未提供 digest。實際查詢只讀一份 JSON，未下載 ZIP；另為相容性探測明確下載原包，在隔離設定下測試載入，calibre 9.19 回報 `No module named 'imghdr'`。

因此本功能能追蹤這個來源，但不代表該上游原版能在目前 calibre 執行。更新器會回報載入失敗並保留舊包，不會自動把本倉庫的 Pillow 修正套進作者原包。此探測未將上游外掛安裝到正式設定或操作任何書庫。

自 0.3.2 起，「自動備份」開關控制是否保留更新前備份，預設勾選且記住設定；取消後僅在安裝期間暫存供一般失敗回復，完成即清除。
