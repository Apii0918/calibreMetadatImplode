# 更新紀錄

## 0.3 — 2026-11-22

- 新增 HamsterExAstris/calibre-azw6-image-merge 的單庫單外掛規則，配對數字標籤與固定 AZW6ImageMerge.zip。
- 支援有／無附件 digest 的判斷、附件 ID 重傳提示，保留下載後名稱、版號及實際相容性驗證。
- 全新安裝仍僅預設本倉庫；重裝與更新不覆蓋使用者來源，連空清單也保留，新增原生測試確認。
- 新增 9 項單一來源及 3 項原生測試，更新內外層指南。實際上游 v1.0.0 在 calibre 9.19 的隔離載入因 imghdr 缺失失敗，未安裝到正式設定。
- GitHub 來源欄支援雙擊開啟庫網址，排序後保持正確來源對應。

## 0.2 — 2026-11-22

- 新增 kiwidude68/calibre_plugins 的前綴發行模式，內建 25 支外掛名稱配對，分頁掃描正式 Release 並依數字版號各自選版。
- 支援 prefix-版本及 prefix-v版本、GitHub 附件 digest、缺少 digest 的明確提示；檢查不先下載 ZIP。
- 安裝上游原包不要求本倉庫身分檔，仍核對 ZIP、名稱、版號與實際相容性；安裝後保存附件及內容 SHA。
- 同名分來源列出，保留原綁定；明確選擇才覆蓋與改綁，同批不可選同名的多個來源。
- 新增前綴規則說明、9 項規則及 4 項原生安裝／同名來源測試；實際掃描 247 筆發行、取得 25 支外掛且未下載 ZIP。

## 0.1.1 — 2026-11-22

- 未安裝項目的目前版號只顯示「未安裝」，已安裝但載入失敗時顯示「載入失敗」。
- 勾選欄改為可點擊的「全選」，支援全選／取消全選切換，略過不可選項目。
- 來源支援直接貼完整 GitHub URL，包括 Release、分支、檔案及 `.git` 網址；自動辨識庫並以完整庫網址顯示及保存。
- 入口移至「偏好設定 → 進階 → GitHub 外掛更新」，改用原生偏好設定外掛，不提供工具列按鈕。
- 偏好設定入口改用專用更新圖示，「管理來源」移至視窗左下方。
- 新增欄位標題排序與升降冪切換；版號按數字段排序，保留勾選外掛的身分對應，「全選」維持勾選切換。
- 更新完成不清空清單或重新抓取來源，只刷新成功項目的版號與狀態，保留其他項目與勾選。
- 新增可記憶的備份資料夾設定，背景安裝與開啟資料夾共用同一路徑；備份 ZIP 採「外掛名稱-原版號.zip」，並在 state.json 記錄檔名。
- 勾選項目經確認後強制安裝，支援內容相同、同版差異、降版及來源切換；保留下載校驗、身分核對、相容性及備份。
- 進階區入口移到第二列左側，補齊身分 SHA、重新綁定與強制更新的完整說明。

- 新增 SOURCE_GUIDE.md，整理來源庫建立、清單與身分檔、發布順序及 SHA／版號／強制安裝流程。

## 0.1 — 2026-11-22

- 新增多個公開 GitHub 庫來源，預設追蹤 SamLaio/calibreMetadatImplode。
- 以固定外掛 ID、來源及本機 SHA 保存綁定；舊包與切換分支由使用者確認。
- 檢查僅抓 Release 資訊與 JSON，先讀身分檔內容 SHA，不同才比較清單版號；只允許較新版。
- 勾選確認後才下載，核對大小、SHA、身分及實際宣告；安裝前保留舊包與登錄備份，失敗回復，保留停用狀態。
- 統一打包加入身分檔、可重現 ZIP 及版本／內容 SHA／ZIP SHA 清單；相同內容重打包不受檔案時間影響，同版內容不同不自動覆蓋。
- 補齊正體中文介面、操作、來源清單規格與驗證限制。
- 內容 SHA 排除身分檔、ZIP 時間與壓縮資訊；另保留完整 ZIP SHA 驗證下載。新增更新器自我更新與成功後才啟用的重啟按鈕。
- 修正 GitHub 將上傳附件名稱的空白轉為句點造成的配對失敗，加入實際命名規則回歸測試。
- 下載網址加入 GitHub 附件 ID，避免同名附件重傳後仍取到 CDN 舊快取。
