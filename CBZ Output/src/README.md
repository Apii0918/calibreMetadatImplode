# CBZ 圖片匯出（CBZ Output）

版本：**0.1**；作者：**SamLiao & Codex**；授權：**GPL v3**；最低 calibre：**9.19.0**。

## 用途

將電子書中的現成圖片依閱讀順序封裝成 CBZ 漫畫檔。這是本倉庫依功能需求獨立重寫的外掛，不是原專案的修改版；原專案功能構想與本次設計見 [記事](./NOTES.md)。

- 依章節閱讀順序及章節內圖片順序輸出，支援 HTML 圖片、SVG 圖片參照與圖片物件。
- 書籍明確指定的封面放在第一頁且只放一次；其他圖片重複引用時保留其頁面位置。不以檔名猜測封面。
- 輸出使用 `000001.png`、`000002.jpg` 等唯一流水號，避免不同資料夾內的同名圖片碰撞。
- 外掛直接寫入收到的圖片內容，不重新編碼或縮放；完整寫好並關閉暫存 ZIP 後才取代目的檔。

## 安裝與使用

1. 在專案根目錄執行 `python build_release.py`，取得 `dist/CBZ Output-zh_TW-release.zip`。
2. 從 calibre「偏好設定 → 外掛 → 從檔案載入外掛」安裝 ZIP，重新啟動。外掛清單顯示 **CBZ Output 0.1**。
3. 若已裝舊 CBZ Output，同名外掛會被本版取代；本版使用獨立的新實作。
4. 選取圖像為主的電子書，開啟「轉換書籍」，右上方輸出格式選 **CBZ**，再開始轉換。不需要工具列按鈕或額外設定。
5. 完成後檢查封面、頁數及順序。來源書檔不會被外掛改寫。

## 範圍與限制

- **不是文字頁面的截圖或渲染工具**。純文字書籍會明確報錯；文字搭配插圖的書籍只會輸出圖片，每次圖片出現視為一頁。
- 以實際章節引用的圖片為主，不把未使用的裝飾素材追加為頁面。若收到的書籍結構沒有章節圖片參照，改以圖片路徑自然排序；calibre 前段流程已刪除的未使用素材無法取回。
- 找不到本機圖片參照時報錯，避免默默漏頁。外部網址圖片不下載，會在轉檔紀錄提示；CSS 背景圖片、影音與純行內向量圖形不轉成頁面。
- 保留 JPEG、PNG、GIF、WebP、BMP、TIFF、AVIF、JPEG XL 或 SVG 的對應格式；閱讀器未必支援全部格式，尤其 SVG 與較新的圖片格式。外掛本身不將它們轉成 PNG。
- calibre 的輸入解析與轉換選項仍可能在此之前改變、縮放或重編碼圖片。需要保留原圖時，請一併核對 calibre 的圖片處理設定。
- 若書籍沒有明確封面資訊，就保留閱讀起點；後備自然排序不保證等同作者閱讀順序。

## 驗證與來源

2026-11-22 在 Windows、calibre **9.19** 通過 **8 項核心測試**及 **3 項實際安裝包轉檔測試**：同名圖片、跨章節閱讀順序、封面、重複引用、中文／編碼路徑、SVG 圖片參照、未使用素材、外部圖片、遺失圖片、失敗保留原檔、原圖位元組與來源書檔保護，以及純文字書籍報錯。

先打包，再於根目錄執行 `python "CBZ Output/tests/test_core.py"` 與 `python "CBZ Output/tests/test_conversion.py"`。測試只使用 `dist/` 下的隔離設定與自製書檔，不操作正式書庫。未實測其他平台及各款漫畫閱讀器。

功能靈感來自 [huyumars/calibre-cbz-convertor](https://github.com/huyumars/calibre-cbz-convertor)（Mars, Hu，發行標籤 v0.0.2）；本倉庫版本獨立管理為 **0.1**。完整設計見 [NOTES](./NOTES.md)，變更見 [CHANGELOG](./CHANGELOG.md)。
