# 設計記事

## 功能構想來源

參考 [huyumars/calibre-cbz-convertor](https://github.com/huyumars/calibre-cbz-convertor) 的產品需求：把電子書內現成的漫畫圖片取出，再包成 CBZ，讓漫畫閱讀器讀取。原專案作者為 Mars, Hu；發行標籤為 v0.0.2。這裡記錄其功能構想，不收錄或複製原專案程式。

重點是「圖片擷取與封裝」，而不是把文字排版後截成一頁頁圖片；原有圖片不必為了改變容器而重新編碼。若書籍提供封面資訊，封面應放在閱讀起點。

## 本倉庫 0.1 的獨立設計

- 使用 calibre 提供的轉換外掛 API 與已解析書籍結構，重新實作所有處理流程。
- 依章節閱讀順序及章節內圖片的出現順序建立頁面；支援 HTML 圖片、SVG 的圖片參照與圖片物件。
- 優先使用書籍明確指定的封面，不以檔名是否含 cover 判斷。封面只放一次，其餘重複引用的圖片依閱讀順序保留。
- 每個頁面分配唯一的流水號檔名，保留 MIME 類型對應副檔名；來源資料夾與原始檔名不會影響命名，也不會造成同名碰撞。
- 沒有章節圖片參照時，才退回圖片路徑的自然排序；一般模式不把未使用的裝飾素材追加成頁面。
- 直接寫入傳入的圖片位元組，先完成暫存 ZIP 並關閉，成功後才取代目的檔；空書、遺失圖片或讀取失敗會明確報錯。
