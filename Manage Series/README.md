# 系列管理（Manage Series）

本倉庫版本：**1.5.5.1**；上游版本：**1.5.5**；作者：**Grant Drake**；正體中文與本地修訂：**SamLiao & Codex**；授權：GPL v3。本修訂版最低 calibre 為 **9.19.0**。

## 用途

在同一視窗整理選取書本的系列名稱與編號，支援拖放、上下移動、依原系列／出版日期／書名排序、鎖定特定編號，以及整數和兩層小數編號。可使用標準系列欄位或自訂的系列類型欄位，也能加入代表待購卷冊的空白書本紀錄。

## 正體中文語言包

使用外掛原生 gettext 語言包，來源為 [zh_TW.po](./src/translations/zh_TW.po)。67 條訊息已填齊，包含主視窗、表頭、右鍵選單、滑鼠提示、鎖定編號與設定視窗；按鍵組合維持原值。打包時編譯為 `translations/zh_TW.mo`，由 calibre 自動載入，其他語言資源與英文原文均保留。

獨立的 `.mo` 只提供翻譯；calibre 9.19 請使用同時包含相容性修正的完整安裝包。

## 安裝與操作

1. 從 [v1.3.24 發行頁](https://github.com/SamLaio/calibreMetadatImplode/releases/tag/v1.3.24) 下載 Manage Series 安裝包；自行打包請使用根目錄的 `build_release.py`，輸出為 `dist/Manage Series-zh_TW-release.zip`。
2. 在 calibre「偏好設定 → 外掛 → 從檔案載入外掛」安裝，重新啟動 calibre。介面語言設為正體中文後會顯示「系列管理」。
3. 在書庫選取要整理的書本，從工具列或「偏好設定 → 工具列和選單」加入的「系列管理」開啟視窗。
4. 選擇系列欄位與名稱、設定起始整數，再調整書本順序。使用左右箭頭改變小數層級，例如 `1、1.1、1.2、2`；鎖定按鈕可保留指定編號。
5. 檢查原有與新系列編號後按「確定」寫回書庫。「取消」不寫回。重複或逆序的編號會顯示警告。

## 限制

- 每次確認只保存最後選定系列欄位的系列修改。若要修改多個系列欄位，請分次開啟與儲存。
- 「還原原有系列編號」還原並鎖定原編號，系列名稱仍以目前輸入為準。
- 移出本次整理清單不會刪除書庫中的書本；加入空白書本並確認時，會新增沒有書檔格式的書庫紀錄。
- 編號衝突警告不會阻止確認，請自行核對後再儲存。書名與出版日期的修改也會一起寫回。
- 本外掛修改書庫中繼資料；書檔內的詮釋資料需另用 calibre 的嵌入流程更新。尚未驗證其他平台與所有較舊 calibre 版本。
