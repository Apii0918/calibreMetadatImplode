# 更新紀錄

## 0.1 — 2026-11-22

- 欄頭「全選」可切換全部勾選／取消；匯出勾選、匯出全部並排，匯入備份獨立一列。驗證完整設定備份可還原工具列按鈕排列。
- 清單加入勾選方塊與「匯出勾選」，依勾選範圍備份外掛與可辨識專用設定；保留一次完整備份與設定還原。
- 首次實作，一次匯出／批次匯入第三方外掛安裝包、版本與啟用狀態。
- 匯出與匯入各自提供是否包含／還原設定的勾選項，預設關閉；可保存 calibre 設定資料夾、工具列、快捷鍵、自訂字串及內建外掛啟用選項，保留本機書庫位置。
- 在「偏好設定 → 外掛」底部取消按鈕左側加入「匯出／匯入外掛…」，不提供工具列按鈕。
- 背景處理、進度、匯入預覽、降版標示、原生相容性檢查、SHA-256／路徑／大小驗證、失敗清單與重新啟動入口。
- 匯出採暫存檔驗證後取代；單支安裝失敗回復原包與登錄；設定寫入失敗嘗試回復，保留無法回復的原檔。
- 10 項格式／設定測試、4 項 calibre 安裝 API 測試及原生偏好設定 GUI 往返驗證通過，納入統一打包。
