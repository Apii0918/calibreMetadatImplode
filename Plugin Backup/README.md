# 外掛備份（Plugin Backup）

版本：**0.1**；作者：**SamLiao & Codex**；授權：**GPL v3**；最低 calibre：**9.19.0**。本倉庫自行開發，使用 calibre 原生外掛安裝 API，沒有獨立上游外掛。

## 用途

將目前使用者安裝的第三方外掛一次匯出成單一 ZIP，保存各外掛安裝包、版本與啟用／停用狀態；可選擇是否一併備份設定。從這個備份批次匯入時，先預覽新增、覆蓋或降版項目，再安裝並提示重新啟動。

入口位於「偏好設定 → 外掛」視窗底部、**取消按鈕左側的「匯出／匯入外掛…」**。不提供工具列按鈕。

## 安裝與操作

1. 在根目錄執行 `python build_release.py`，取得 `dist/Plugin Backup-zh_TW-release.zip`。
2. 從 calibre「偏好設定 → 外掛 → 從檔案載入外掛」安裝 ZIP，重新啟動 calibre。外掛清單名稱為 **Plugin Backup 0.1**。
3. 再開啟「偏好設定 → 外掛」，按底部的「匯出／匯入外掛…」。
4. **匯出：**在清單前勾選外掛，按欄頭「全選」可全部勾選，再按可全部取消；部分勾選時按下會全部勾選。第一列「匯出勾選」只備份勾選項目，「匯出全部」則備份全部；第二列「匯入備份」開啟還原流程。兩者皆可勾選「一併備份設定」，預設不包含設定。
5. **匯入：**按「匯入備份」，選擇本工具產生的備份。核對各項新增／覆蓋／降版；備份含設定時，可另外勾選「一併還原設定」，預設不勾選。
6. 按「匯入」後等待背景作業完成，再按「重新啟動 calibre」。作業中不能關閉此視窗，避免中斷安裝。

可在另一台電腦先安裝本外掛，再讀取備份。無需逐支挑選安裝包；備份中沒有的既有外掛會保留。

## 設定備份範圍

- 「匯出勾選」只收錄勾選外掛的自訂字串與可辨識的專用設定檔（`plugins/` 下同名檔案／資料夾，及程式以固定字串宣告的 `JSONConfig` 路徑）；不包含其他外掛、共用工具列／快捷鍵及內建外掛設定。動態產生路徑或共用檔案中的設定無法可靠歸屬，不收錄；需要這些設定時請使用完整備份。
- 「匯出全部」勾選設定時，備份 calibre 設定資料夾中的一般檔案及子資料夾，包含外掛設定、工具列、快捷鍵、各外掛的自訂字串，以及內建外掛明確設定的啟用／停用狀態。
- 完整設定包含工具列按鈕所在位置與排列順序，還原後重新啟動生效。若其他外掛提供按鈕群組／子選單，其配置存在 calibre 設定資料夾時也會收錄；書庫資料庫或外部檔案中的配置不包含。勾選匯出不包含共用工具列配置。
- 不收錄快取、日誌、隱藏檔、鎖定檔、Python 快取，以及含 `metadata.db` 的書庫資料夾。設定中的外掛 ZIP 與安裝登錄檔不直接複製還原，改由備份清單及 calibre 安裝 API 建立正確的本機路徑。
- 還原設定時，保留目前電腦的書庫位置、書庫使用路徑紀錄與安裝識別；其他同名設定檔會被覆蓋，不在備份中的檔案保留。書庫、書籍、自訂欄位及儲存在書庫資料庫內的外掛選項不包含在此備份。
- 放在 calibre 設定資料夾以外的自訂設定、憑證或外部程式不會自動收錄。設定中的其他外部路徑保持原值，換電腦後可能需要調整。
- 只有全部外掛成功匯入後才還原設定；若有外掛失敗，會列出原因並保留目前設定。
- 設定可能包含帳號、API 金鑰或其他私人資料，ZIP **未加密**，請自行保管；只匯入可信任的備份。

## 檢查與失敗處理

安裝前檢查備份格式、路徑、數量、檔案大小及 SHA-256；預覽檢查不執行備份裡的外掛程式。真正匯入時由 calibre 檢查版本、平台與外掛識別。

不相容或被 calibre 封鎖的外掛會列為失敗。單支安裝失敗時回復原有安裝包、安裝登錄及啟用狀態，其他項目繼續。設定寫入失敗時嘗試回復已改動的檔案；若回復也失敗，錯誤訊息會指出原檔保留位置。匯出先寫暫存 ZIP，驗證完成才取代目的檔，失敗不破壞既有備份。

支援最多 1,000 支外掛；每包壓縮及解壓後各上限 256 MiB，外掛包合計 2 GiB。設定最多 10,000 個檔案，每檔 64 MiB、合計 256 MiB；清單本身上限 2 MiB。超限會報錯，不會默默省略。

## 限制與驗證

- 只封裝使用者安裝的第三方外掛 ZIP；不複製 calibre 內建程式或系統套件。也不能將任意一批下載的 ZIP 當成本工具的備份直接匯入。
- 匯入會依備份覆蓋同名外掛，即使備份版本較舊；預覽會標示降版。安裝後與設定還原後均需重新啟動。
- 新增底部按鈕是執行期間的介面擴充，不修改 calibre 安裝檔；外掛需維持啟用。
- 2026-11-22 在 Windows、calibre **9.19** 通過 **10 項備份格式／設定測試、4 項原生外掛安裝 API 測試，以及原生偏好設定 GUI 完整往返測試**，涵蓋損壞備份、路徑保護、覆蓋／降版、停用狀態、失敗回復、可選設定、底部入口、全選切換、兩列按鈕及工具列排列還原。
- 測試使用 `dist/` 下的獨立設定與書庫，未操作正式書庫。其他平台、所有第三方外掛組合，以及外部設定位置尚未驗證。

測試入口為 `tests/test_core.py`（一般 Python）、`tests/test_calibre.py` 與 `tests/test_gui.py`（`calibre-debug -e`）。後兩者必須先在 `dist/` 下的獨立 `CALIBRE_CONFIG_DIRECTORY` 安裝實際安裝包；GUI 測試另設定 `QT_QPA_PLATFORM=offscreen`，結果寫入該設定目錄的 `gui-result.json`。
