# 編輯工具袋（Diaps Editing Toolbag）

本倉庫版本：**0.5.0.1**；上游版本：**0.5.0**；作者：**DiapDealer（Doug Massay）**；正體中文與本地修訂：**SamLiao & Codex**；授權：**GPL v3**。本修訂版最低需求為 **calibre 9.19.0**。

## 用途

在 calibre「編輯書本」提供三項工具，直接修改目前開啟書籍的內容：

| 工具 | 功能 |
| --- | --- |
| 編輯 span 與 div | 依標籤、屬性及屬性值移除包裝標籤、修改完整屬性字串或轉換標籤，支援正規表示式與巢狀標籤。也能處理 `p`、`i`、`em`、`b`、`strong` 等元素。 |
| 進階智慧標點 | 分別控制西文智慧引號、破折號及省略號，選擇 Unicode 或數字字元實體輸出，並支援撇號例外詞檔案。保留原有字元實體。 |
| 將 CSS 的 cm 轉為 em | 依上游固定係數 **2.37106301584** 將外部 CSS 中的公分尺寸轉為 `em`，四捨五入到小數兩位。 |

三項工具均可切換「目前檔案」與「全書」範圍。這是編輯器外掛，入口位於「編輯書本」的外掛選單或外掛工具列。

## 安裝與操作

1. 在專案根目錄執行 `python build_release.py`，取得 `dist/Diaps Editing Toolbag-zh_TW-release.zip`。
2. 在 calibre「偏好設定 → 外掛 → 從檔案載入外掛」安裝 ZIP，重新啟動。外掛管理清單仍使用原名 **Diaps Editing Toolbag**，保留上游識別與設定。
3. 開啟一本書的「編輯書本」視窗，從「外掛」選單使用三項工具；如需範圍切換與自訂設定，將工具加入外掛工具列後使用其下拉選單。
4. 編輯標籤時指定標籤／屬性／值，再選擇移除或修改。一般模式比對完整屬性值；正規表示式從值的開頭比對。「沒有任何屬性」只比對完全沒有屬性的標籤。
5. 智慧標點可分別勾選引號、省略號與破折號方式。撇號例外檔建議採 UTF-8，每行一詞，不含撇號，例如 `tis`。
6. 處理完成後使用「查看變更差異」核對結果，再用編輯器「儲存」寫入書檔。每次處理前會建立檢查點。

正體中文介面由原生 `translations/zh_TW.mo` 載入，來源 [zh_TW.po](./src/translations/zh_TW.po) 共 **71 條**訊息，於打包時編譯。標籤、屬性名稱、範本與內部設定值維持原樣，保留其他上游語言資源。標籤編輯與智慧標點視窗的「外掛說明」均提供內建中文操作文件。

## 限制與還原

- 移除標籤會保留其中的文字和子元素，但可能改變排版。修改屬性時，若未勾選「複製原有屬性字串」，新字串會取代全部原有屬性；留白會移除全部屬性。請使用正確的 HTML 語法及雙引號。移除 `id`／`href` 可能破壞目錄或註腳連結。
- HTML 解析器可能重新序列化標籤，請核對差異；嚴重損壞或標籤不配對的書檔應先修復。
- 智慧標點以西文排印為主，不會將中文引號統一為「」或『』。
- CSS 轉換沿用上游固定係數，不依每個元素的實際字級計算。只處理外部 CSS 最上層的一般規則及 `@page`，不遞迴處理 `@media` 等巢狀規則，也不處理 HTML 的行內樣式。請確認換算後的版面。
- 結果視窗的「關閉」只關閉結果，**不會還原修改**。可用編輯器檢查點還原。全書處理按「取消」會停止後續檔案，已完成的修改保留；處理錯誤則回到執行前檢查點。
- 智慧標點原快捷鍵與 calibre 9.19 的「另存副本並在此編輯」衝突，本修訂版不指定其預設快捷鍵，可在編輯器偏好設定自行設定。標籤編輯原預設 `Ctrl+Shift+Alt+E` 保留。
- 尚未驗證其他平台、舊版 calibre 與所有第三方外掛組合。

## 來源與本地修訂

來源為 [dougmassay/toolbag-calibre-plugin](https://github.com/dougmassay/toolbag-calibre-plugin/tree/4589e1ad30421d1a7698fc26464cb20336a61771)，固定基準提交 **`4589e1ad30421d1a7698fc26464cb20336a61771`**；支援討論見 [MobileRead](https://www.mobileread.com/forums/showthread.php?t=251365)。原始程式、圖示、SmartyPants 等資源的作者與授權標示均保留。

本地修正涵蓋 Qt 6 列舉與 `exec()` 呼叫、全書進度視窗的正常結束及錯誤傳遞、目前檔案結果清單、Python 3 可重複使用的撇號例外詞清單，以及衝突快捷鍵。補上原生正體中文語言包與兩份中文內建說明，納入專案統一打包。

## 驗證

2026-11-22 在 Windows、calibre **9.19** 使用獨立設定目錄與測試 EPUB，安裝實際 ZIP 後通過：

- **七項隔離測試**：標籤目前檔案／全書處理、巢狀與正規表示式／無屬性條件、標點選項與重複例外詞、全書標點與儲存重開、CSS 目前／全書及正負值／`@page`／未修改內容保護、四個原生對話框與完整語言包／中文說明、取消與錯誤回復呼叫。
- **兩階段原生編輯器測試**：真正的 Edit Book 視窗載入三項工具、建立檢查點、執行三項全書操作並使用原生「儲存」；結束後以另一個編輯器程序重新開啟，核對三項結果及中文、實體與連結識別保留。

測試以 Qt 離屏模式執行，不使用正式書庫。重跑時先打包，以 `dist/` 下的獨立 `CALIBRE_CONFIG_DIRECTORY` 安裝 ZIP，再執行 `calibre-debug -e "Diaps Editing Toolbag/tests/test_toolbag.py"`；原生編輯器腳本為 `tests/test_gui_roundtrip.py`，以 `TOOLBAG_GUI_BOOK` 指定 `dist/` 下的測試 EPUB，`TOOLBAG_GUI_PHASE=edit`／`reopen` 分兩個程序執行。可用 `TOOLBAG_FIXTURE` 指定檔名執行前一測試腳本產生測試 EPUB。設定 `QT_QPA_PLATFORM=offscreen`，離屏 WebEngine 可使用 `QTWEBENGINE_CHROMIUM_FLAGS="--no-sandbox --disable-gpu"`。
