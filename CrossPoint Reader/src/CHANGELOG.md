# 更新紀錄

## 0.2.8.1 — 2026-11-22

- 從使用者舊 0.1.0 問題重現出發，整合官方 0.2.8，保留 MIT 授權、設定鍵、傳輸與預設關閉的最佳化選項。
- 嚴格辨識 UDP 探索回覆與有效連接埠；連接前驗證 HTTP 檔案清單，避免無關服務觸發 calibre 裝置介面。
- 增加連線健康檢查、讀取失敗清理與重試冷卻；退出／停止後不立即重新探索，並確實關閉探索 socket。
- 新增 134 條原生正體中文翻譯，涵蓋設定、進度、摘要、錯誤與文字最佳化提示；四項語言／設定／協定測試通過。
- 使用原生 BookList，讀取失敗不再當作空書庫。七項測試及本機 HTTP 服務驗證通過，未驗收實體閱讀器。
